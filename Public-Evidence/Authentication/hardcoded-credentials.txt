Vulnerability: Hardcoded Administrator Credentials
Application: OWASP Juice Shop
Target: http://127.0.0.1:3000

Affected file:
main.js

Location:
Line 7482

Finding:
Testing username and password values were embedded
in publicly accessible frontend JavaScript.

Validation:
The discovered test credentials successfully authenticated
against POST /rest/user/login.

HTTP Response:
200 OK

Account:
[REDACTED]

Account Role:
Administrator

Impact:
An attacker who discovers and uses exposed credentials
may obtain administrator-level access.

Recommendation:
Remove credentials from client-side JavaScript.
Rotate exposed passwords.
Use secure authentication and access controls.
Review administrator account activity.

Note:
Actual credentials have been removed from this public evidence.
Testing was performed in a local OWASP Juice Shop lab.
